CivicMind – Smart Citizen Grievance Management System

Overview

CivicMind is a full-stack web application that enables citizens to report civic issues online and allows government officers to manage, track, and resolve complaints efficiently.

This project was developed to simplify grievance management by providing separate dashboards for citizens, officers, and administrators.

---

Features

Citizen

- User Registration & Login
- Report Complaints
- Track Complaint Status
- View Complaint History

Officer

- View Assigned Complaints
- Update Complaint Status
- Manage Citizen Requests

Admin

- Dashboard
- Complaint Analytics
- Manage Users
- Monitor Overall System

Installation

Frontend

Open "index.html" using Live Server or any browser.

Backend

1. Open the backend project in IntelliJ IDEA.
2. Configure MySQL.
3. Update database credentials in "application.properties".
4. Run the Spring Boot application.
5. Open the frontend in your browser.
